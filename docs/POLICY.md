# 收录规则

这份文档定义「什么算免费午餐」。规则不复杂，但会被严格执行——**规则的松紧决定了这张表还值不值得看**。

## 四条硬规则

一条资源要进表，必须同时满足：

### 1. 长期免费

指的是**没有结束日期的免费额度**：每月重置的免费层、每天重置的免费额度、永久免费的模型档位。

以下不算：

- 注册赠送的试用金（"送 $5，30 天有效"）
- 限时活动、发布会促销
- 需要消费才解锁的"免费"（"充 10 美元后免费模型额度提升"——这条本身可以写进备注，但不能当作收录理由）

### 2. 门槛分级：信用卡/邀请码不收，实名/手机进二级表

门槛分两档处理：

- **一概不收**：信用卡、邀请码。"免费但要绑卡"和"不免费"在使用者视角上差别很小，而邀请码直接违背"能直接用"。
- **可以收，但进二级表**：实名认证、手机号。国内厂商的长期免费层几乎全在这档（智谱、硅基流动、讯飞星火……），对中文用户往往最实用——一刀切不收等于把最有用的一批资源挡在门外。它们与零门槛主表**分开呈现**，门槛在 README 表头、网页角标和 `data.json` 里全程标注。

这一条由 `scripts/lib.py` 的 `Requirements` 强制校验：`credit_card` / `invite_only` 为 `true` 构建直接失败；`kyc` / `phone` 为 `true` 不再拒稿，而是自动打上 `tier: kyc`，进「📇 需实名/手机」二级表。

> 这是 2026-11 的口径变更（由来见 [ROADMAP.md](ROADMAP.md)）：此前所有门槛一律不收，代价是「国内可直连」长期为空。现在的选择是把最有用的国内资源收进来，用分级和标注把筛选成本留给自己，不转嫁给读者。

### 3. 官方渠道

必须是服务商自己提供的公开产品或公开免费层。

以下一律不收：

- API 中转站、公益站、共享 key
- 逆向网页端得到的接口（reverse-engineered endpoint）
- 需要破解、绕过区域限制才能用的服务
- 任何形式的"白嫖"脚本

理由有三：随时失效、无法承诺证据、以及会把仓库拖进不必要的法律风险。

### 4. 有证据

每条必须带：

- `verification.checked_at`：你**亲自**看到官方页面写着这个额度的日期
- `verification.evidence`：那个官方页面的链接（或实测记录）

没核验过的条目允许存在，但只能标 `method: unverified`，在表格里显示为「⏳ 待核验」。**不允许为了好看而编一个日期。**

## 标签规范

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `cn_access` | `direct` | 大陆网络无需代理，稳定可用 |
| | `partial` | 多数网络能通，但会间歇超时、偶发拦截 |
| | `blocked` | 大陆网络无法访问，必须自备出口 |
| | `unknown` | 没人实测过（欢迎补测） |
| `tier`（派生） | `zero` | 注册门槛全 false，进零门槛主表 |
| | `kyc` | 需实名（`kyc: true`）或手机（`phone: true`），进二级表 |

`unknown` 不是贬义。诚实地写 `unknown`，比抄一个没验证过的 `direct` 有价值得多。

`tier` 不需要手写，由 `requirements` 派生：只要 `kyc` 或 `phone` 任一为 `true` 就是 `kyc` 档。两者不一致的情况不存在，也就无从写错。

## 过期与归档

- 核验日期超过 **60 天**：自动降级为「待复核」，CI 每周提示一次
- 服务下线或取消免费额度：把 `archived` 设为 `true`，并写清 `archived_reason`
- 归档条目仍留在仓库里，但不出现在默认视图，只在「已归档」分组可见

保留归档记录是有意为之：**"这家曾经免费、现在不免费了"本身就是有价值的信息**，能省掉别人一次踩坑。

## 商业中立

- 本项目与所列服务商无任何关联
- 不收受推广费用，不接受付费排序
- 若将来出现赞助，必须在数据里用 `sponsored: true` 标注，并在 README 顶部显著说明
- 邀请链接、返利链接一律视为垃圾 PR
