# 被排除的服务，以及为什么

**知道什么不能用，和知道什么能用一样重要。**

这张表记录那些"看起来该收录、实际不符合口径"的服务。目的有两个：省掉别人重复调研的时间，以及说明我们的筛选标准不是随口定的。

> 如果你认为某条判断过时了（比如某家取消了绑定信用卡的要求），欢迎提 PR 更正——把条目从这张表挪回 `data/`。

## 因为下线

| 服务 | 情况 | 备注 |
| --- | --- | --- |
| GitHub Models | 2026-07-30 全面下线 | playground、模型目录、推理 API 与 BYOK 全部停止，官方建议迁往 Azure AI Foundry。仓库里留了归档条目做示例。 |

## 因为没有永久免费层

| 服务 | 情况 | 备注 |
| --- | --- | --- |
| Cerebras | 需绑定付款方式 | 官方 FAQ 明确写着"没有永久免费层"：注册送 $5，30 天过期，不绑卡则 API 不可用。 |
| Together AI | 注册赠金制 | 属于试用额度，不是长期免费。 |
| Fireworks / Hyperbolic / Novita / Nebius | 注册赠金制 | 同上，额度用完即止，且有有效期。 |
| NVIDIA NIM | 积分制 | 注册赠送调用积分，是否长期免费、积分是否重置都随政策变化，暂不收录。 |

## 因为门槛

| 服务 | 门槛 | 备注 |
| --- | --- | --- |
| Mistral La Plateforme | 手机验证 | 免费实验层本身存在，但注册需要手机验证。 |
| Cohere | 试用 key | 试用 key 有速率限制且条款限定为非商用，不属于长期免费。 |
| 智谱 GLM 系列 | 实名 / 手机 | 免费档位（如 GLM-Flash）确实长期免费，但需要绑定手机或实名。 |
| 硅基流动 SiliconFlow | 手机 | 部分模型长期免费，注册需手机号。 |
| 魔搭 ModelScope | 阿里云账号 + 实名 | 每日 2000 次调用很香，但实名是硬门槛。 |
| 讯飞星火 Spark Lite | 实名 | 永久免费档位，需实名认证。 |
| 腾讯混元 Lite | 实名 | 同上。 |
| 百度千帆 | 实名 | 免费额度按模型赠送，需实名。 |
| 火山方舟 / 豆包 | 实名 + 赠金 | 以试用额度为主。 |

> 国内厂商这一栏是本项目最纠结的地方：**它们对中文用户其实最有用**，但几乎全部要求实名或手机号。当前选择是宁可空着也不放低标准，是否要开一个「需实名但长期免费」的二级表，见 [ROADMAP.md](ROADMAP.md) 里的讨论。

## 因为不合规

| 类型 | 情况 |
| --- | --- |
| API 中转站 / 公益站 | 用别人共享的 key 转发，稳定性、隐私、法律主体都不明确，部分会记录并盗用请求内容。 |
| 逆向接口（把网页端包成 API） | 违反服务条款，随时失效，账号有被封风险。 |
| 共享账号池 | 同上，且有明显的安全风险。 |
| 需要破解区域限制才能用的服务 | 不属于"能直接用"。 |

## 因为不是一个东西

| 项目 | 说明 |
| --- | --- |
| Ollama / vLLM / llama.cpp 本地部署 | 确实免费，但属于"你自己有硬件"，不是托管 API 服务，不该和免费额度混在一张表里。未来可能单开一节。 |
