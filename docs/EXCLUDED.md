# 被排除的服务，以及为什么

**知道什么不能用，和知道什么能用一样重要。**

这张表记录那些"看起来该收录、实际不符合口径"的服务。目的有两个：省掉别人重复调研的时间，以及说明我们的筛选标准不是随口定的。

> 如果你认为某条判断过时了（比如某家取消了绑定信用卡的要求），欢迎提 PR 更正——把条目从这张表挪回 `data/`。

## 因为下线

| 服务 | 情况 | 备注 |
| --- | --- | --- |
| GitHub Models | 2026-07-30 全面下线 | playground、模型目录、推理 API 与 BYOK 全部停止，官方建议迁往 Azure AI Foundry。仓库里留了归档条目做示例。 |

## 因为没有永久免费层

| 服务 | 情况 | 备注 |
| --- | --- | --- |
| Cerebras | 需绑定付款方式 | 官方 FAQ 明确写着"没有永久免费层"：注册送 $5，30 天过期，不绑卡则 API 不可用。 |
| Together AI | 注册赠金制 | 属于试用额度，不是长期免费。 |
| Fireworks / Hyperbolic / Novita / Nebius | 注册赠金制 | 同上，额度用完即止，且有有效期。 |
| NVIDIA NIM | 积分制 | 注册赠送调用积分，是否长期免费、积分是否重置都随政策变化，暂不收录。 |
| 腾讯混元 | 一次性资源包 | 2026-11 核实：免费部分是「一次性免费资源包」（多模型共享 100 万 tokens，1 年过期作废），属试用性质。曾全面免费的 hunyuan-lite 已从现行定价页和模型表消失（平台正迁移至 TokenHub），「长期免费」无法从现行官方页面核实，暂不收录。 |
| 百度千帆 | 新用户赠金 | 2026-11 核实：2024 年「ERNIE Speed/Lite 全面免费」已成历史，现行《模型列表》已无这两款模型；免费部分是新用户每模型 100 万 tokens（3 个月过期）+ 20 元代金券（1 个月过期），属试用性质。 |
| 火山方舟 / 豆包 | 试用赠金 | 免费部分以一次性试用赠金为主（注册赠送 token 额度、限期用完），不满足「长期免费」，和门槛无关。 |
| 讯飞星火 Spark | 免费档性质存疑 | 2026-11 核实：官方页面只有「免费测试体验」（X1 10 万 tokens、星辰 MaaS 20 元额度，均一次性领取）、`Spark-X2.6-4B` 标注「限时免费」，以及「含免费模型」的措辞；**「Spark Lite 永久免费」未在现行官方页面找到依据**。经典 Lite 还是 WebSocket 私有协议、非 OpenAI 格式。有官方定价页写明长期免费的证据，欢迎 PR 收录。 |

## 因为门槛

> **2026-11 口径变更**：需要实名/手机但长期免费的服务已转入**二级表**正常收录（见 [POLICY.md](POLICY.md)），不再堆在本页——智谱、硅基流动、魔搭 ModelScope 等现在能在 README 的「📇 需实名/手机」二级表里找到。注意「门槛放宽」只放宽注册身份，**「长期免费」这条没有放宽**：腾讯混元、百度千帆虽也是实名门槛，但因只有试用赠金而进了上面的「没有永久免费层」。本节只剩仍然不收的：

| 服务 | 门槛 | 备注 |
| --- | --- | --- |
| Mistral La Plateforme | 手机验证 | 免费实验层本身存在，但注册需要手机验证，且大陆网络不可达，收录价值低。 |
| Cohere | 试用 key | 试用 key 有速率限制且条款限定为非商用，不属于长期免费。 |

> 国内厂商曾是本项目最纠结的地方：**它们对中文用户其实最有用**，但几乎全部要求实名或手机号。2026-11 起我们选择开二级表把它们收进来（`tier` 字段区分、门槛全程标注），讨论过程见 [ROADMAP.md](ROADMAP.md)。

## 因为不合规

| 类型 | 情况 |
| --- | --- |
| API 中转站 / 公益站 | 用别人共享的 key 转发，稳定性、隐私、法律主体都不明确，部分会记录并盗用请求内容。 |
| 逆向接口（把网页端包成 API） | 违反服务条款，随时失效，账号有被封风险。 |
| 共享账号池 | 同上，且有明显的安全风险。 |
| 需要破解区域限制才能用的服务 | 不属于"能直接用"。 |

## 因为不是一个东西

| 项目 | 说明 |
| --- | --- |
| Ollama / vLLM / llama.cpp 本地部署 | 确实免费，但属于"你自己有硬件"，不是托管 API 服务，不该和免费额度混在一张表里。未来可能单开一节。 |
